# Nafissa & Issa — Invitation numérique

Invitation au mariage religieux de Nafissa et Issa, le lundi 14 décembre 2026 à 14h, à Ouaga 2000 (Ouagadougou).

À l’ouverture, la porte d’une mosquée s’ouvre sur l’invitation : arche ivoire sur ciel émeraude, compte à rebours, verset 30:21, lieu sur Google Maps, invocation pour les mariés et bouton de partage.

## Utilisation

Tout tient dans un seul fichier : `index.html`. Ouvrez-le dans un navigateur, ou activez GitHub Pages sur ce dépôt pour obtenir un lien à partager.

## Personnaliser

Au début du script, dans `index.html` :

```js
const CONFIG = {
  date: '2026-12-14',   // AAAA-MM-JJ
  heure: '14:00',       // heure de Ouagadougou (UTC+0)
  ...
};
```
